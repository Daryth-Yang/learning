# 🌀 螺旋式 AI PM 课程(主课表)

> **这是 Daryth 的主课表**(2026-06-05 重构)。学习方式:螺旋式 —— 5 个板块齐头并进,
> 每个板块从入门开始,一圈圈加深,从易到难。
> 知识分类见 [`../knowledge-map.md`](../knowledge-map.md);详细资源/作业见 module-1~4(主题内容库)。

---

## 为什么这样排(设计原则)

1. **螺旋(spiral)**:不是"啃完一个领域再下一个",而是先把 5 个板块的**入门**都过一遍 → 再各加深一层 → 再加深。知识体系同时长起来,更全面。
2. **交替(interleaving)**:每天主菜 + 一道轮换配菜,5 板块一周内都碰到。
3. **主菜固定是 AI 技术**:只有它内部有强依赖(LLM→RAG→Agent),不能打乱;其他 4 板块可平行积累,当配菜每天轮。
4. **由易到难**:圈1 最浅(求广)→ 圈4 最难(实战)。

---

## 总览:4 圈,由易到难

| 圈层 | 目标 | 难度 | 周数 | 验收 |
|---|---|---|---|---|
| 🟢 **圈 1 · 入门圈** | 5 板块最浅层,建立全局直觉,"每个词都听过" | 最易 | ~3 周 | 入门小测 |
| 🟡 **圈 2 · 基础圈** | 核心吃饭家伙,面试主战场 | 中 | ~4 周 | 基础验收 |
| 🟠 **圈 3 · 进阶圈** | 能做决策、能跟工程师对话 | 较难 | ~4 周 | 进阶验收 |
| 🔴 **圈 4 · 实战圈** | 独立作品 + 简历 + 模拟面试 | 最难 | ~3 周 | 综合验收 |

> 总时长 ~14 周(原 19-22 周,入门圈刻意浅、求广不求深)。节假日按节奏偏好顺延。

---

## 每天的节奏(适用所有圈)

每天约 2 小时:**🥘 主菜(AI技术,~70%)+ 🥗 当天轮换配菜(~30%)**

| 学习日 | 🥘 主菜 | 🥗 配菜(每天轮一个板块) |
|---|---|---|
| 周一 | 当圈 AI 技术主题 | 🛠️ 工程系统 |
| 周二 | 当圈 AI 技术主题 | 💼 PM 能力 |
| 周三 | 当圈 AI 技术主题 | 🎨 AI 产品设计 |
| 周四 | 当圈 AI 技术主题 | 🌐 行业认知 |
| 周五 | 复盘 + 自测 | 把本周 5 板块笔记串成一张图 |
| 周末 | 综合实操 / 周作业(同时用到多板块) | |

> 配菜顺序可微调(某天想多补工程就多配),但**一周内 5 板块都要碰到**。

# 🟢 圈 1 · 入门圈(~3 周)

**目标**:5 个板块的最浅层。学完能"每个词都听过、能用大白话说个大概"。求广不求深。

### 各板块入门内容

| 板块 | 圈 1 学什么 |
|---|---|
| 🤖 AI 技术(主菜) | LLM 在做什么(神经网络直觉)、Token、上下文窗口、幻觉、Temperature、模型生态(GPT/Claude/Qwen/DeepSeek)、多模态概念 |
| 🛠️ 工程 | 看懂一段代码大概在干嘛、什么是 API、JSON 长啥样怎么读 |
| 🎨 产品设计 | AI 产品 vs 传统产品的根本区别、对话式交互的直觉 |
| 💼 PM 能力 | 什么是需求、什么是 PRD(先看真实样例)、什么是 A/B 测试(概念) |
| 🌐 行业 | 读 AI 新闻、拆解 1 个你天天用的 AI 产品(豆包/Kimi) |

### 周安排

| 周 | 🥘 主菜(AI技术) | 🥗 配菜轮换重点 | 周末产出 |
|---|---|---|---|
| **W1** | 神经网络直觉 + Token + 上下文(3Blue1Brown / Karpathy) | 一~四:读1段代码 / 看1份真PRD / AI产品vs传统 / 读1篇AI新闻 | `notes/圈1/W1-llm入门.md` + 1篇产品拆解 |
| **W2** | 幻觉 + Temperature + 模型生态(GPT/Claude/Qwen/DeepSeek) | 一~四:什么是API / 什么是需求 / 对话式交互直觉 / 竞品拆解 | 模型生态对比小表 + 笔记 |
| **W3** | 多模态概念 + 串联复习(LLM全貌) | 一~四:JSON怎么读 / 什么是A/B测试 / 信任与可控性 / 行业趋势 | 圈1 知识体系图 + 入门小测 |

> 📎 详细资源/视频链接见 [`module-1-ai-tech.md`](module-1-ai-tech.md) W1-W2;PRD样例见 [`module-3-pm-basics.md`](module-3-pm-basics.md)。

### 圈 1 验收(入门小测)
- 能用大白话讲:LLM / Token / 上下文 / 幻觉 / Temperature
- 能说出 4 个主流模型 + 各自特点
- 能讲清 AI 产品和传统产品的 1 个根本区别
- 能读懂一段简单 JSON 在表达什么

# 🟡 圈 2 · 基础圈(~4 周)

**目标**:核心吃饭家伙,面试主战场。学完能讲清 Prompt/RAG/Agent + 写简单 PRD + 懂基础数据和商业模式。

### 各板块基础内容

| 板块 | 圈 2 学什么 |
|---|---|
| 🤖 AI 技术(主菜) | Prompt 工程系统化、RAG 是什么/为什么、Agent 是什么/ReAct/Tool Use |
| 🛠️ 工程 | API 怎么调用、前后端分工、SQL 基础查询 |
| 🎨 产品设计 | 多轮对话设计、不确定性处理、HITL 人机协作 |
| 💼 PM 能力 | 写一份简单 PRD、核心数据指标、商业模式(SaaS/API) |
| 🌐 行业 | 每周 1 个竞品拆解 + 1 篇商业化文章 |

### 周安排

| 周 | 🥘 主菜(AI技术) | 🥗 配菜轮换重点 | 周末产出 |
|---|---|---|---|
| **W4** | Prompt 工程系统化(结构化/Few-shot/CoT) | API调用 / 核心数据指标 / 多轮对话设计 / 竞品拆解 | Prompt 迭代日志(v1→v5) |
| **W5** | RAG 是什么、为什么、完整流程直觉 | 前后端分工 / 写简单PRD开头 / 不确定性处理 / 商业化文章 | RAG 概念笔记 |
| **W6** | Agent 是什么、ReAct、Tool Use | SQL基础查询 / PRD继续 / HITL人机协作 / 竞品拆解 | Agent 概念笔记 |
| **W7** | 串联:Prompt/RAG/Agent 三者关系 | 综合配菜 / 完成第一份简单PRD / 商业模式SaaS vs API | 基础验收 + 第一份完整简单PRD |

> 📎 Prompt 详见 module-1 W3;RAG 见 W5;Agent 见 W6;对话UX 见 [`module-2-ai-product.md`](module-2-ai-product.md) W3;PRD 见 module-3 W2。

### 圈 2 验收(基础)
- 能讲清 Prompt 工程的核心技巧 + 举例
- 能讲清 RAG 工作原理和它解决什么问题
- 能讲清 Agent 是什么、ReAct 怎么回事
- 交一份格式规范的简单 PRD
- 能说出 2 种 AI 商业模式的差异

# 🟠 圈 3 · 进阶圈(~4 周)

**目标**:能做产品决策、能跟工程师深入对话。把工程盲区(8 个 Q)清掉。

### 各板块进阶内容

| 板块 | 圈 3 学什么 |
|---|---|
| 🤖 AI 技术(主菜) | **技术选型(Prompt vs RAG vs 微调)⭐**、RAG 进阶(分块/重排/评估)、Agent 进阶(MCP/多智能体)、评测与安全、微调/LoRA 概念 |
| 🛠️ 工程 | 部署/打包/构建、反向代理、目录约定(清掉 open-questions 的 Q6-Q14) |
| 🎨 产品设计 | 评测体系设计、完整 Agent 产品设计 |
| 💼 PM 能力 | 完整 PRD、定价/PMF、成本优化(Token/缓存)、项目管理 |
| 🌐 行业 | 伦理合规、深度趋势分析 |

### 周安排

| 周 | 🥘 主菜(AI技术) | 🥗 配菜轮换重点 | 周末产出 |
|---|---|---|---|
| **W8** | 技术选型 ⭐ Prompt vs RAG vs 微调 | 部署/打包概念 / 完整PRD / 评测体系设计 / 伦理合规 | **律师助手技术选型报告**(可给老板看) |

> 📎 技术选型详见 module-1 W4(重头戏);RAG进阶 W5;Agent/MCP W6;评测安全 W7;部署/代码 W8;商业/项管 见 module-3 W4;Agent产品设计 见 module-2 W2/W4。

### 圈 3 验收(进阶)
- 给一个场景能独立做技术选型(Prompt/RAG/微调)并讲清成本-效果权衡
- 能讲清 RAG 进阶优化手段
- 能讲清 MCP 是什么、和 Function Calling 的关系
- 能设计一个产品的评测 + 安全方案
- 能讲清一个 AI 产品的商业模式 + 定价逻辑
- 工程 8 个 Q 全部能用大白话解释
