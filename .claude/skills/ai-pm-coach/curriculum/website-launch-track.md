## 📝 各讲知识点详解(讲透一个填一个)

### 第 1 讲:基础角色(开店四件套)✅ 已坐实(2026-06-11 晚)
- 服务器=一直开着的店面房子;后端=后厨(干活);前端=点单台(看得见);域名=店地址(找到你)
- ✅ **复述结论**:四件套全答对。服务器="运行的坑位"(精准);后端答对还自发说出"后端→返回→前端→用户看到"整条链;前端=用户看得见能用;域名=地址。**真坐实,非白天夹生态**。

### 第 2 讲:前后端怎么对话 ✅ 已坐实(2026-06-11 晚)
- 请求/响应=点单/上菜;静态资源=现成瓶装(图片/视频固定文件)vs API=现做奶茶(动态数据)
- baseUrl=后端基础地址(打底);URL=完整网上地址(协议+域名+路径,URL 含域名);完整URL = baseUrl + 具体路径(/chat)
- ✅ **复述结论(深度超预期)**:
  - 静态/动态自悟"答案预先弄好 vs 现场处理"
  - API 升华为"**能力调用**",且分清前端调后端(基础)/ 后端调第三方(进阶)
  - 从 URL **自己悟出"接口对接 / 联调"**:把后端 URL 告诉前端、前端接对应 URL 实现对接
- ⚠️ 她 .cn 域名,baseUrl 要写 `api.no7exp.cn` 别写 .com

### 第 3 讲:上线手续·中国特色 ✅ 已坐实(2026-06-11 晚)
- 备案=应用的营业执照(中国法律强制,没它国内打不开,一次性手续、等审核7-15天)
- 备案找谁办:报国家工信部,但**必须通过云服务商(腾讯云)代提交**
- 轻量服务器=99元/年的"我是腾讯云客户"入场券,纯为够资格备案,**不跑代码**(代码在Cloudflare免费跑);每年续费否则备案注销
- 国外后缀:备案有"白名单",.com/.cn/.net 行,.io/.app/.dev 很多不行;她买 .cn 选对
- **成本两笔**:71元/2年域名(地址)+ 99元/年服务器(备案入场券)
- ✅ **复述结论**:三考题全过;**自己梳理出成本结构**(PM算账思维);澄清"跑腿费"=不存在(备案免费,只有99顾客费这笔)

### 第 5 讲:部署运维(全⚪了解即可)

**服务器初始化(2026-06-11 截图补)**:给服务器装系统+设密码 = 给"店面毛坯房"做基础装修
- 操作系统/Ubuntu = 服务器的底层系统(电脑的Windows);LTS=长期稳定版(无脑选);root=超级管理员账号(总钥匙)
- 她只需照着点:选Ubuntu→24.04 LTS→设12位密码记好→无需备份→确定。⚪不用懂原理

#### SSH(已起头)
- SSH = 远程进服务器的"钥匙+加密通道"(人不在机房,远程连进去操作)
- SSH 三选一(她 no7 真实决策):(a) IP+root密码=直接交家门钥匙最快但险 (b) 网页终端自己粘=钥匙不出门最稳 (c) 密钥对/公钥=办门禁卡最规范
- 教练建议 (b)(她新手+负责人,钥匙不出门最稳);**最终由她拍板**
