# 🗺️ AI PM 知识地图(5 大板块)

> Daryth 的 AI PM 知识全景图。回答"知识到底分成哪几块、每块学多深"。
> 配套课表见 [`curriculum/spiral-curriculum.md`](curriculum/spiral-curriculum.md)(螺旋式 4 圈,5 板块齐头并进)。
> 建立日期:2026-06-05

---

## 核心认知(先看这个)

1. **目标定位:应用型 AI PM**(占市场 80-90% 岗位)—— 懂技术原理 + 行业洞察 + 商业化落地,**不深钻算法**。
2. **5 大板块深度不同**:AI 技术要精,工程只需够用,产品设计是你的老本行优势,PM 能力是转型补课。
3. **学习方式:螺旋式**(见课表)—— 每个板块从入门开始,一圈圈加深,5 板块同时长。

深度标签:🟢 **必精**(吃饭家伙) / 🟡 **够用**(能聊能决策) / ⚪ **知道就行**(名词级)

---

## 🤖 板块 1:AI 技术认知(核心地基 · 花最多时间)

> AI PM 区别于普通 PM 的根本。面试一半的题在这。**课表里它是每天的"主菜"**(内部有强依赖,必须按序学)。

| 子领域 | 内容 | 深度 | 主要在第几圈 |
|---|---|---|---|
| LLM 原理 | 大模型在做什么、Token、上下文窗口、幻觉 | 🟢 | 圈1 |
| 模型生态 | GPT/Claude/Gemini/Qwen/DeepSeek、多模态、Temperature | 🟢 | 圈1 |
| Prompt 工程 | 结构化(角色/上下文/格式/约束)、Few-shot、CoT | 🟢 | 圈2 |
| RAG 检索增强 | 是什么/为什么/完整流程(分块→嵌入→检索→重排→注入) | 🟢 | 圈2→圈3 |
| Agent | 定义、ReAct、Memory/Planning、Tool Use、Function Calling、MCP | 🟢 | 圈2→圈3 |
| 技术选型 ⭐ | Prompt vs RAG vs 微调 怎么选(最高频面试决策题) | 🟢 | 圈3 |
| 评测与安全 | 怎么评估、幻觉、越狱、Prompt 注入、红队测试 | 🟢 | 圈3 |
| 微调概念 | Fine-tuning vs 预训练、LoRA(什么时候用,不学实现) | 🟡 | 圈3 |
| 模型内部 | 注意力(MHA/MQA/GQA)、RoPE、RLHF/PPO/DPO、MoE、分布式训练 | ⚪ | 名词级,圈1/3 附录 |

## 🛠️ 板块 2:工程系统常识(够跟工程师对话就行)

> ⭐ 这就是"前端/后端/运维/部署"所在地。**只学到能听懂,不学写代码。** 求广不求深。
> Daryth 的 open-questions 里 8 个工程 Q 全在这——当前最大盲区,但要的是广度。

| 子领域 | 内容 | 深度 | 主要在第几圈 |
|---|---|---|---|
| 代码可读性 | 看懂一段代码在干嘛、变量/函数/类、import | 🟡 | 圈1→圈3 |
| 数据格式 | JSON 长啥样怎么读、YAML | 🟡 | 圈1 |
| 前端/后端 | 谁负责啥、API 怎么调、HTTP 请求 | 🟡 | 圈2 |
| 数据库/SQL | SQL 基础查询、数据库概念 | 🟡 | 圈2 |
| 部署/打包/构建 | .exe/.zip、build 脚本、安装包、命令行参数 | ⚪ | 圈3 |
| 运维/架构 | 反向代理(Nginx)、后台进程、目录约定(src/dist/) | ⚪ | 圈3 |

## 🎨 板块 3:AI 产品设计(设计师老本行 + AI 升级)

> Daryth 的 UI 设计底子在这里直接复用,是相对优势。

| 子领域 | 内容 | 深度 | 主要在第几圈 |
|---|---|---|---|
| AI 产品原则 | AI 产品 vs 传统产品、能力边界、可控性、信任建立 | 🟢 | 圈1 |
| 对话式 UX | 多轮对话设计、不确定性处理、错误兜底、流式体验 | 🟢 | 圈2 |
| Agent 产品设计 | HITL 人机协作、任务流程设计 | 🟢 | 圈3 |
| 评测体系(产品侧) | 怎么从产品角度定义"好"、指标设计 | 🟡 | 圈3 |

## 💼 板块 4:PM 通用能力(转型必补)

> 从设计师转 PM 的新东西。面试和工作天天用。

| 子领域 | 内容 | 深度 | 主要在第几圈 |
|---|---|---|---|
| 需求分析 | 用户需求→技术需求、需求挖掘、用户访谈 | 🟢 | 圈1→圈2 |
| PRD 写作 | 写清楚给工程师、格式规范、覆盖完整 | 🟢 | 圈2→圈3 |
| 数据分析 | 关键指标、A/B 测试、漏斗、SQL 分析 | 🟢 | 圈2→圈3 |
| 商业化 | SaaS/PaaS/API/按效果付费、定价、PMF、Token 计费 | 🟢 | 圈3 |
| 成本管理 | Token 优化、上下文 Trim、模型路由、缓存 | 🟢 | 圈3 |
| 项目管理 | 推进、跨职能协作、风险、排期 | 🟡 | 圈3 |
