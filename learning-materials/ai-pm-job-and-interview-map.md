## 🎯 一句话结论(先看这个)

你现在的 8 周课程表 **和大厂真实要求高度吻合**。市场招的是**应用型 AI PM**(占 80-90% 岗位):
- **不要求**你能手推 Transformer、写 PPO 代码、调分布式训练;
- **要求**你懂原理直觉、能跟工程师对话、能做技术选型(RAG/微调/Prompt)、能设计评估、能算成本、能讲商业化。

所以下面给每个知识点打了 **PM 相关度标签**,帮你区分「必会」和「知道名词即可」,别把精力浪费在工程师深水区。

| 标签 | 含义 | 学习策略 |
|---|---|---|
| 🟢 **PM 必会** | 面试高频会问,必须能用大白话讲清 | 重点学,要能复述+举例 |
| 🟡 **PM 该懂** | 懂原理直觉,能跟工程师对话,可能被问 | 学到"能听懂能讨论"即可 |
| ⚪ **了解即可** | 工程师深水区,PM 知道这个名词存在就行 | 记住名词+一句话作用,不深究 |

## 📋 Part 1:真实大厂招聘需求(官方 JD)

### 1.1 上海人工智能实验室 — AI 产品经理(社招,工程通道)

**岗位职责**:
- 对接客户/解决方案团队,理解业务场景,引导、澄清并拆解需求,**独立输出产品需求文档(PRD)**
- 协调研发、测试、设计团队,推动需求落地;完成开发、测试、上线
- 产品上线后**数据监测与评估**,实时响应,优化迭代
- 项目汇报、典型产品资料输出;收集反馈推进功能迭代

**任职要求**:
- 3-5 年产品经验,参与或负责过 AI 产品开发
- 业务理解、逻辑分析、需求转化、方案输出能力强
- **具备独立负责 0→1 产品落地经验**
- 熟练用 Office、Visio、XMind、Axure
- 本科及以上,理工类优先

### 1.2 字节跳动 — AI 产品经理(社招,要点)

- 负责字节业务的 LLM 应用探索;AI 平台/产品的规划、设计、落地
- 判断行业趋势,结合最前沿技术和产品形态,打造**标杆性 AI 产品**
- 推进模型训练评估所需的**数据标注、质量管理**,提出模型优化的数据建议
- 要求:对**预训练、精调、提示**等大模型底层技术有一定理解;能从用户视角研究产品;强沟通推动能力

### 1.3 腾讯 — AI 产品经理(要点)

- 明确要求:**能用 SQL 分析 A/B 测试数据**、绘制 AI 功能落地甘特图、撰写技术方案 BP(商业计划书)

### 1.4 联想 / 其他企业(共性)

- 本科及以上,计算机/软件/产品相关优先;部分要 5 年以上经验
- 需求调研与分析、竞品分析、协调跨职能团队、上线后数据监控

### 1.5 三类 AI PM 岗位(决定你学多深)

| 类型 | 占比 | 要求 | 适不适合你 |
|---|---|---|---|
| **专业型**(底层大模型/算法平台) | 10-20% | 硕士+,深钻算法 | ❌ 暂不追 |
| **应用型**(AI 商业化落地) | 80-90% | 懂技术+行业洞察+商业化运营 | ✅ **你的主战场** |
| **AIGC 内容方向** | — | 内容生态+运营 | 可选 |

> **给 Daryth 的解读**:几乎所有 JD 都出现「需求拆解→PRD→协调团队→上线→数据监测优化」这条主线,加「懂大模型原理但不必精算法」。这正好对应你的弱项清单(看代码/技术原理/PRD/商业)—— 课程已对准。

## 📋 Part 2:面试题库(150+ 真题,按维度归类)

> 来源:datawhale hello-agents 面试总结、wdndev/llm_interview_note、woshipm 100 题、各大厂面经。
> ⚠️ 工程师八股(🔴/⚪)给你**判断深度**用,不是让你全背。PM 重点在 🟢🟡。

### A. LLM 基础认知(🟢 PM 必会)
1. 用大白话解释什么是大语言模型 / Transformer 在做什么?
2. 什么是 Token?上下文窗口、最大输出长度是什么关系?
3. 什么是幻觉(Hallucination)?为什么会出现?怎么缓解?(技术+产品两面)
4. 涌现能力(Emergent Ability)是什么?
5. NLP 和 LLM 最大的区别是什么?
6. 主流开源/闭源模型有哪些?各自特点?(GPT/Claude/Gemini/Qwen/DeepSeek)
7. Prefix LM 和 Causal LM 的区别?
8. 什么是「复读机问题」?

### B. Prompt 工程(🟢 PM 必会)
9. Prompt 工程有哪些核心技巧?(角色设定/Few-shot/CoT)
10. 什么是思维链(Chain-of-Thought)?为什么有效?
11. 同一个需求,Prompt 写法不同结果差异很大,你怎么系统化优化?

### C. RAG 检索增强(🟢 PM 必会 + 🟡 进阶)
12. 🟢 解释 RAG 工作原理。和微调相比解决了什么问题?优势?
13. 🟢 一个完整的 RAG 流水线包含哪些步骤?(数据准备→生成)
14. 🟡 文本切块(chunking)大小和重叠怎么选?背后的权衡?
15. 🟡 怎么选嵌入模型(Embedding)?评估指标有哪些?
16. 🟡 除了基础向量检索,还有哪些提升检索质量的技术?(重排/混合检索)
17. 🟡 解释 "Lost in the Middle" 问题,怎么缓解?
18. 🟡 怎么全面评估一个 RAG 系统?(检索+生成两阶段指标)
19. 🟡 什么场景用知识图谱/图数据库替代向量检索?
20. 🟡 了解哪些开源 RAG 框架(如 RAGFlow)?怎么选型?
21. 🟡 搜索系统和 RAG 有什么区别?

### D. Agent 智能体(🟢 PM 必会 + 🟡 进阶)
22. 🟢 怎么定义一个基于 LLM 的 Agent?核心组件有哪些?
23. 🟢 解释 ReAct 框架(思维链 + 行动如何结合)

## 🪜 Part 3:难度分级知识模块(从简单到难)

> 这是把上面所有题涉及的知识点,按**学习难度**重排成 4 层。每层学完再上一层。

### L1 · 入门层(概念直觉,先建立"地图")
> 目标:听到这些词不慌,能用大白话解释。
- 大模型/Transformer 在做什么(直觉,非数学)🟢
- Token / 上下文窗口 / 最大输出 🟢
- 幻觉是什么、为什么有 🟢
- 模型生态:GPT / Claude / Gemini / Qwen / DeepSeek 🟢
- 多模态基础概念 🟡
- 开源 vs 闭源 🟢

### L2 · 基础层(PM 核心地基)
> 目标:这是面试主战场,要能讲清+举例。
- Prompt 工程系统化(角色/Few-shot/CoT)🟢
- RAG:是什么、为什么、完整流程 🟢
- Embedding / 向量检索 直觉 🟡
- **技术选型:Prompt vs RAG vs 微调**(⭐最高频决策题)🟢
- 微调 / LoRA 概念(什么时候用,不学怎么实现)🟡
- Agent:定义、ReAct、Tool Use、Function Calling 🟢
- 评估基础:为什么难、人工评估、LLM-as-Judge 🟢

### L3 · 进阶层(跟工程师对话 + 产品决策)
> 目标:能参与技术方案讨论,能做产品级决策。
- RAG 进阶:切块策略、重排、Lost in Middle、检索+生成评估指标 🟡
- Agent 进阶:Memory、Planning、Multi-Agent、A2A、MCP 🟡
- 成本管理 / Token 优化 / 上下文 Trim 策略 🟢
- 评估体系设计:事实性、安全、红队测试、上线后监控 🟢
- 商业化:SaaS/API/按效果付费、定价、PMF、数据飞轮 🟢
- 数据标注流程设计、A/B 测试、SQL 分析 🟢
- AI 产品的对话 UX、不确定性处理、PRD 写作 🟢

### L4 · 深水区(⚪ 了解名词即可,不深钻)
> 目标:知道这些词指什么、大致作用,能听懂工程师在说什么。**不要花大力气**。
- 注意力细节:MHA/MQA/GQA、RoPE、位置编码
- 解码策略:Beam/Top-K/Top-P/Temperature(这个建议懂一点 🟡)
- 架构:Encoder/Decoder-Only、MoE、Scaling Laws
- 对齐:RLHF、PPO、DPO、GRPO、Reward Hacking
- 训练/推理工程:分布式训练、量化、vLLM、KV Cache
- VLM 内部:CLIP、LLaVA 连接方式

### 🔴 现有课程的 3 个缺口(建议加进去)

1. **成本 / Token 优化**(G 区,🟢 高频题)—— 当前没单独章节。建议加进 **W2 或 W6**,或在 W4 选型时一起讲(选型本质就是成本/效果权衡)。
2. **商业化模块**(I 区,🟢 高频题)—— 在你的 **Module 3 W4**,时间靠后。但面试爱问。建议:从现在起每周副线读 1 篇商业化文章(你的副线任务已有这项,激活它)。
3. **PRD 实战 + 数据/SQL/A-B 测试**(H/J 区)—— 在 Module 3。面试明确要(腾讯 JD 点名 SQL)。建议:Module 4 作品集时每个项目都配一份 AI 产品 PRD。

### ✅ 不用动的部分
- L4 深水区(M 区)**保持"了解即可"**,W1/W2 给你一张名词表背过就行,别陷进去。这是你作为应用型 PM 最该克制的地方 —— 省下时间打 L2-L3。
